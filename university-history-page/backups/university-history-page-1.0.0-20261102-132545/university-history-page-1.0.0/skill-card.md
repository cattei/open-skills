# 高校发展史图谱

**把一所中国高校的百年变迁，渲染成一个能双击打开的 HTML 页面。**

## Description<br>

输入一所大学的校名，输出一个自包含的 HTML 单文件：一条按年排序的总览时间轴，外加校名演变、校址变迁、隶属变更、校长更迭、学科建设、学科评估、政策影响七个分层维度，以及学院设置、学位点、专业设置三张表。

页面不联网、不引 CDN、不加载外部字体，断网可看、可发给别人、可直接归档或打印。全量索引收录 3016 所高校，随包带 142 所重点高校的完整发展史数据。

## Use Case<br>

- **考生与家长**：判断一所学校的校史含金量——哪些校名是后来挂靠的、哪些是合并来的、哪些是独立发展。
- **教育研究者**：单独观察一个维度的规律（校长更迭节奏、院系调整的波及范围），不必在混合时间线里大海捞针。
- **高校从业者**：理解政策如何驱动变迁，把"1952 院系调整 → 我院被拆出 → 更名 → 迁址"的因果链串起来。
- **内容制作**：一份可直接嵌入报告、发微信或打印的单文件页面，不依赖任何运行时。

## Deployment Geography<br>

数据覆盖中国大陆全部普通高等学校（3016 所），随包完整发展史覆盖 985 / 211 / 双一流共 142 所。渲染在本地完成，不涉及任何地域性服务端依赖。

## Known Risks and Mitigations<br>

- **把缺失数据当成事实**：源数据存在"年份不详 / 层次待补充 / 任期不详"的空洞。**缓解**：页面一律如实标注缺失，不做任何推测填充；`selftest.py` 有不变量专门守住这条。
- **学科评估被编造年份**：源数据只有"第 N 轮"，没有年份。**缓解**：左列显示轮次（如"第四轮"）而非年份，绝不把公开常识当作源数据写进页面。
- **校长列表重复刷屏**：源数据同一任期有 2–3 条重复记录（整体重复率 41.5%），现任者还会逐年补记录。**缓解**：生成阶段按(姓名, 起年, 止年, 归一职务)去重并合并开放任期；`selftest.py` 验证重复为 0。
- **校名匹配错校**：中文校名存在大量包含关系（"安徽大学" vs "安徽大学（xx）"）。**缓解**：解析顺序为完全同名 → 历史校名 → 包含匹配取最短，并支持先 `--search` 核对 uid。
- **误以为覆盖全部学校**：索引 3016 所但只有 142 所有完整数据。**缓解**：非精选学校渲染明确的降级页，写明"完整数据未随包"，绝不假装有数据；`--list` 用 ★ 标记覆盖范围。
- **单文件被当成实时数据**：HTML 是某一时点的快照。**缓解**：页脚写明数据生成时间与来源说明，提示重新生成方式。

## Skill Output<br>

一个 UTF-8 编码的 `.html` 单文件（典型 40–65 KB）：

- 深蓝渐变页头 + 事实卡（建校年 / 省份 / 城市 / 层次 / 性质 / 隶属 / 历史校名数）
- 校名沿革条：`安徽省立大学 → 省立安徽大学 → 国立安徽大学 → 安徽大学`
- 总览时间轴：按年排序，每条标注所属维度
- 七个维度区块：事件列表 + 表格，每个区块标条数
- 页脚：数据来源、生成时间、缺失值口径说明

同时提供 `--json` 结构化摘要（uid / 是否精选 / 各维度条数 / 时间轴节点数），便于其他程序消费。

## Ethical Considerations<br>

- **不做录取判断**。本技能只呈现历史事实，不评价学校优劣、不预测录取概率、不给报考建议。
- **不编造史料**。缺失即标注缺失；宁可页面留白，不填猜测。校史涉及具体人物与政治运动，措辞一律照源数据，不做主观解读。
- **尊重数据边界**。技能包内只有公开的教育部高校信息与校史资料，不含任何个人隐私、家庭或健康数据。
- **署名与责任**：对外署名「酷乐猫」；页面明确标注"数据生成时间"，使用者需自行核对时效性。
