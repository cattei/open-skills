# 高校发展史图谱

把一所学校的百年变迁渲染成**一个 HTML 文件**：双击能开、断网能看、发给别人不丢样式。
纯标准库 Python 生成，不调 LLM，不联网，零边际成本。

## 解决什么

「这所学校是怎么变成今天这样的」——散在几十份文件、上百个年份里。
本技能把它压成一条可读的时间轴 + 按维度分层的细节，且**每个数字都能追到源数据**。

典型用途：

- 考生/家长判断**校史含金量**：哪些是合并来的、哪些是独立发展、哪些校名是后来挂靠的
- 研究者单独看一个维度：只看校长更迭规律、只看院系调整影响，不在混合时间线里捞针
- 做汇报/科普材料：一份可直接嵌入文档或发微信的单文件页面

## 怎么用

```bash
# 按 uid 渲染（输出 ahu.html 到当前目录）
python scripts/render.py --uid ahu

# 按中文校名渲染
python scripts/render.py --name 安徽大学 --out ./安徽大学发展史.html

# 先查有没有这所学校
python scripts/render.py --search 安徽
python scripts/render.py --list 安徽          # ★ 表示随包带完整数据

# 只要结构化摘要，不要 HTML
python scripts/render.py --uid pku --json
```

脚本位置在**本技能目录**下（`scripts/render.py`），`data/` 同级。
其他 agent 调用时把路径换成技能实际所在目录即可。

## 参数

| 参数 | 说明 |
|---|---|
| `--uid` | 学校 uid，如 `ahu`（安徽大学）、`pku`（北京大学） |
| `--name` | 中文校名，支持历史校名与包含匹配 |
| `--out` | 输出路径；缺省 `<uid>.html` |
| `--stdout` | 打到标准输出，不写文件 |
| `--json` | 输出摘要 JSON（uid / featured / 各维度条数 / 时间轴节点数） |
| `--search` | 按关键词搜校名，返回 uid |
| `--list` | 按省份列出，`★` 标记随包覆盖 |
| `--data` | 数据目录，缺省技能内 `data/` |

## 两层数据（重要）

| 层 | 覆盖 | 内容 | 体积 |
|---|---|---|---|
| 索引层 `index.json` | **全部 3016 所** | 校名 / 省份 / 城市 / 层次 / 建校年 | 285 KB |
| 精选层 `featured-*.json` | **142 所**（985 + 211 + 双一流） | 7 维度全量事件 + 学院 / 学位点 / 专业 | 2.1 MB |

- 任何一所学校都能**查到**（命中索引）；
- 只有精选学校能**渲染完整发展史**；
- 非精选学校会渲染一个**明确的降级页**：只显示基本信息 + 说明"完整数据未随包"，
  **绝不假装有数据、绝不编造事件**。

要扩覆盖范围，重新生成数据即可：

```bash
python scripts/build-data.py --source <Project-UniversityHistory/software/src/data> --featured-top 300
```

## 七个维度

| 维度 | 内容 | 渲染形态 |
|---|---|---|
| 校名演变 | 旧名 → 新名 + 原因类型 + 描述 | 事件列表 |
| 校址变迁 | 地点 + 类型（主校区/战时/分校） | 事件列表 |
| 隶属变更 | 旧隶属 → 新隶属 | 事件列表 |
| 校长更迭 | 姓名 + 任期 + 职务（校长/党委书记/副校长） | 事件列表 |
| 学科建设 | 学科 + 动作（院系调整/学科升格/入选双一流） | 事件列表 |
| 学科评估 | 学科 + 评级（A+/A/B+/…/C-） | 事件列表（左列显示轮次） |
| 政策影响 | 政策名 + 影响类型 + 影响详情 | 事件列表 |
| 学院设置 | 学院 + 学位点数 + 专业数 | 表格 |
| 学位点 | 学位点 + 层次 + 类型 + 所属学院 | 表格 |
| 专业设置 | 专业 + 所属学院 + 状态 | 表格 |

另有**总览时间轴**：把校名/校址/隶属/学科/政策五个维度合成一条按年排序的线，
每年每维度只留一条，避免淹没在几百个事件里。

## 输出契约

单文件 HTML，`<style>` 内联，**零外链**：

- 无 `<link>`、无 `<script src>`、无 `http` 引用、无 `@font-face`、无 `@import`
- 系统字体栈（-apple-system / Segoe UI / Noto Sans SC / Microsoft YaHei / PingFang SC）
- 响应式：≥640px 三栏时间轴，<640px 折成两栏
- 支持 `@media print`（打印时保留配色，维度区块不跨页断）
- 典型体积：精选学校 40–65 KB，非精选 6–7 KB

## 边界与明确不做

- **不编造**。源数据没有的年份显示"年份不详"，没有的层次显示"层次待补充"，
  没有的任期显示"任期不详"。宁可留空，不做推测填充。
- **不覆盖未收录学校**。查不到就说查不到，并给出候选。
- **不做跨校对比**。一次只渲染一所；对比需要另建技能。
- **不联网**。数据在包内，离线可用。
- **不是 Neo4j 图谱**。本项目线上产品是 Neo4j + Next.js 时序图谱（多校关系网络），
  本技能是它的**单校渲染分身**：同一份数据真源，产出可离线分发的 HTML。

## 数据真源与同步

- 真源：`Project-UniversityHistory/software/src/data/*.json`（24 个文件）
- 本技能 `data/` 是从真源**生成**的紧凑视图，不手改。
- 重新生成：`python scripts/build-data.py --source <真源目录>`
- 生成后必须跑 `python scripts/selftest.py`，退出码 0 才算可用。

## 已知数据缺陷（已在生成阶段修复，勿回退）

这几条都是实测踩到的，修法写在 `build-data.py` 里，改脚本时不要"顺手简化"掉：

1. **校长维度没有 `year` 字段**，年份在 `year_start` / `year_end`。
   渲染时取 `year` 会得到满屏"年份不详"。
2. **学科评估只有"第 N 轮"，没有年份**。不能编造轮次对应年份，
   左列改显示轮次（`第四轮`）。
3. **校长记录重复率 41.5%**。同一任期在源数据里有 2–3 条（`title` 混写
   `president` / `校长` / `party_secretary` / `党委书记`）。已按
   (姓名, 起年, 止年, 归一职务) 去重。
4. **现任者逐年补记录**。同一人同职务会留下 2023/2024/2025 多条，
   已合并为一条开放任期；同人同职务的多段"在任"只保留最新。
5. **`year_end=9999` 是"至今在任"哨兵**，直接渲染会显示 9999 年。已归一为空。
6. **学位点 `level` 大量是"待补充"**，不能当成硕士/博士渲染。

## 自检清单

交付前跑一遍：

```bash
python scripts/selftest.py        # 6 案例 + 10 条不变量，退出码 0
```

覆盖：精选/非精选/查无此校/按名解析/JSON/按省列出 + 自包含性、校长年份、
评估轮次、校长去重、在任合并、哨兵年份、学位层次如实标注。

手工验收建议：真浏览器打开生成的 HTML，检查
