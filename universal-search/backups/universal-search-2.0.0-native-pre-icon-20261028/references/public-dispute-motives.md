# 公众人物争议、诉讼与动机核验

适用于“某名人/企业家起诉、发律师函、爆料或公开喊话，背后目的是什么”等问题。

## 1. 先核验行动到底发生到哪一步

“告”可能指完全不同的状态：

1. 公开扬言或媒体放风；
2. 律师函、警告函或平台投诉；
3. 已递交起诉材料；
4. 法院受理或正式立案；
5. 已开庭、调解、撤诉或和解；
6. 已有判决、上诉或执行。

这些状态不能互相替代。优先寻找案号、法院、当事人准确名称、案由、受理日期、诉请、原始法律文书和可追溯的律师/当事人声明。

查不到公开案号时只能写“公开渠道尚未核到”，不能据此断言没有起诉；很多记录存在公开延迟或访问限制。

## 2. 分别核验三类内容

- 行为事实：谁在哪天做了什么，有无原始记录；
- 法律评价：是否构成侵权、谁更可能胜诉，需要适用规则与完整事实，不能只凭立场；
- 内心动机：为什么做、想获得什么，通常需要推断，不能由行为本身唯一推出。

## 3. 动机使用竞争假设

按材料选择真正不同的假设，不必每次凑齐：

- H1 权利救济：停止侵害、澄清事实、赔偿或恢复名誉；
- H2 声誉管理：控制负面叙事、公开表明态度、修复支持者信心；
- H3 威慑与谈判：提高对方成本、促使删文/道歉/和解；
- H4 流量或商业收益：为产品、项目、账号、交易或市场叙事获得关注；
- H5 关系与联盟：回应合作方、粉丝、投资人或其他利益相关者；
- H6 混合动机：多个目标同时存在。

每个假设必须导出不同观察点。例如：

- 若主要追求法律救济，后续通常能看到持续推进程序、明确诉请和证据提交；
- 若主要追求舆论效果，需观察法律行动与宣传节奏的耦合、传播投入及后续是否持续推动程序；
- 若主要用于谈判，可能看到私下沟通、撤诉、和解或诉求变化。

以上只是判别线索，不是单独定罪式证据。

## 4. 利益与时间线

建立事件前后时间线，检查：

- 争议内容出现、回应、律师函、立案、开庭和判决的先后；
- 同期是否有产品发布、融资、代币/市场波动、商业合作或舆情危机；
- 谁实际获得曝光、流量、价格变化、谈判空间或声誉修复；
- 谁承担了律师费、声誉风险、反诉风险和机会成本；
- 法律行动之后是否真的持续推进，还是只停留在公开声明。

“时间接近”和“可能受益”只能支持进一步调查，不能单独证明目的。

## 5. 表达边界

- 当事人明确说出的目的，只能证明“他如此宣称”，不自动证明真实目的；
- 使用“更支持”“目前不能排除”“该解释仍缺少……”等有边界的措辞；
- 不把“炒作”“敲诈”“恶意诉讼”“造假”等定性词写成事实，除非有充分且适用的直接依据；
- 不用动机判断替代对原始主张真假的核验；
- 必须写出替代解释、最脆弱推断和会改变结论的新证据。

## 6. 该类报告的核心句式

> 目前能直接确认的是【行为事实与阶段】。关于目的，E1、E2 在前提 A1 下更支持 H2，而 H1 仍有 E3 支持；由于缺少 G1，不能把 H2 写成唯一真实动机。若后续出现 F1，则应上调/推翻当前解释。
